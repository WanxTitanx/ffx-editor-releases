# Spira Reforge Studio

Official binary downloads for the FINAL FANTASY X / X-2 HD Remaster editor.

[Download the latest version](https://github.com/WanxTitanx/ffx-editor-releases/releases/latest) · [All releases](https://github.com/WanxTitanx/ffx-editor-releases/releases)

## Português (Brasil)

Este repositório público contém somente a distribuição do Editor: pacotes para Windows x64 e Linux x64, notas de versão, manifestos e checksums. O desenvolvimento e o histórico do código-fonte são privados.

Abra os releases, baixe o pacote da sua plataforma e extraia todo o conteúdo antes de executar o Editor. As notas de cada versão informam os requisitos e as limitações daquele pacote.

Os arquivos de binários já publicados mantêm seus nomes e conteúdo. As licenças e atribuições incluídas nesses pacotes continuam preservadas; esta mudança de hospedagem não altera suas licenças. Consulte [LICENSE](LICENSE), [NOTICE](NOTICE) e os avisos de cada pacote.

## English

This public repository contains only Editor distributions: Windows x64 and Linux x64 packages, release notes, manifests and checksums. Development and source-code history are private.

Open Releases, download the package for your platform and extract its entire contents before starting the Editor. Each release's notes describe its requirements and limitations.

Previously published binary files retain their names and contents. Licenses and attributions included in those packages are preserved; this hosting change does not alter their licenses. See [LICENSE](LICENSE), [NOTICE](NOTICE) and each package's notices.

GitHub's automatic “Source code” archives contain only this download documentation and license notices, not Editor source code.

Spira Reforge Studio is an unofficial community project and is not affiliated with Square Enix.
