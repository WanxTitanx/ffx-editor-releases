# Spira Reforge Studio downloads

This repository is the official public download channel for **Spira Reforge Studio**, formerly known as FFX Project Editor.

The application source remains in its private development repository. Public releases here contain the portable application, a SHA-256 checksum, a machine-readable release manifest, installation notes, and preserved third-party notices.

## Latest release

Download the latest Windows x64 build from [Releases](https://github.com/WanxTitanx/ffx-editor-releases/releases/latest). Extract the entire ZIP, then run `FFXProjectEditor.exe`.

The current free release is not Authenticode-signed, so Windows SmartScreen may show the normal warning for a new unsigned application. Verify the ZIP against the accompanying `.sha256` file before running it.

Launcher binaries use their own repository: [ffx-mod-launcher-releases](https://github.com/WanxTitanx/ffx-mod-launcher-releases).
