PRE-EXISTING COMPONENTS WITH INCOMPLETE PROVENANCE
--------------------------------------------------

The following components remain because the project owner explicitly accepted the existing set and
requires functional parity. They are hash-pinned and must not be silently replaced or expanded:

* FFXED.jar - legacy Java save-editor integration. The Studio also contains independently maintained
  native C# save editing code; the JAR remains for sections not yet ported.
* Binarysharp.MSharp / MemorySharp64 and Keystone.Net/keystone x64 - memory tooling. Only the x64
  native payload is shipped; the VC++ 2013 x64 prerequisite is verified separately.
* fsbext - FSB extraction helper.
* fsbankcl/fsbankex bundle and its adjacent runtime DLLs - FMOD-adjacent bank tooling.

These entries are marked BUNDLED_OWNER_ACCEPTED_RISK in the dependency ledger. vbfextract is not in
the package; it remains a user-provided/deferred capability. New third-party tools remain deny-by-default.
