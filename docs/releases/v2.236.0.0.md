## Spira Reforge Studio v2.236.0.0

Primeira distribuição pública nativa para **Linux x64**, junto com a atualização Windows x64 da mesma versão.

### Novidade principal: Linux nativo

- Executável Linux self-contained (sem necessidade de instalar .NET): extraia o `tar.gz`, dê permissão de execução a `FFXProjectEditor` e execute.
- Viewers Web (NoClip/WebView) no Linux reportam estado "indisponível" de forma segura (fail-closed, sem navegador, sem servidor).
- vgmstream incluído para decodificação de áudio; FFXED/Java permanecem exclusivos do pacote Windows.
- Smoke externo: 31/31 módulos públicos navegados com projeto real, imutabilidade total do pacote e do projeto, 9 idiomas com telas distintas.

### Windows

- Mesma versão do pacote Windows: 672 arquivos, verificado, smoke em VM Windows limpa como usuário normal.
- Diferenças de bytes vs v2.235.4.0 limitadas a 11 arquivos first-party com versão embutida (exe/dll/satélites); todo o restante idêntico.

### Instalação (Windows)

1. Baixe `Spira-Reforge-Studio-v2.236.0.0-win-x64.zip`.
2. Extraia o ZIP inteiro para uma pasta gravável.
3. Execute `FFXProjectEditor.exe`.
4. Consulte `WINDOWS_FIRST_RUN.txt` se o Windows solicitar pré-requisitos.

### Instalação (Linux)

1. Baixe `studio-core-linux-x64-2.236.0.0.tar.gz` e o sidecar `.sha256`.
2. Verifique: `sha256sum -c studio-core-linux-x64-2.236.0.0.tar.gz.sha256`.
3. Extraia: `mkdir studio && tar -xzf studio-core-linux-x64-2.236.0.0.tar.gz -C studio`.
4. Execute: `./studio/FFXProjectEditor` (o app host já sai executável no arquivo).
- Requisitos de sistema derivados de `ldd` real: glibc x86-64, X11/XWayland e bibliotecas padrão de fontes/compressão listadas em `release/linux-runtime-prerequisites.json` no repositório-fonte.
