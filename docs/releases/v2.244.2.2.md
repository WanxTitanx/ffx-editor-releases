## What's in 2.244.2.x

**Contract debt from v2.244.2.1 cleared:**

- **RID-conditional Avalonia backend** — the `Avalonia.Win32`→`Avalonia.Desktop` swap had dragged 6 Unix DLLs into the Windows ZIP (`Avalonia.Desktop/.X11/.FreeDesktop/.Native`, `Tmds.DBus.Protocol`, `System.IO.Pipelines`). Windows builds now reference `Avalonia.Win32` + `UseWin32()`; Linux dev/publish keeps `Avalonia.Desktop` + `UsePlatformDetect()`. The win-x64 package is back to the verified **672-file** set.
- **Formal noclip CDN exception** — `z.noclip.website` removed from the global deny patterns; the `NoclipDataBootstrap` literal in the app assembly is now a sha256-pinned `REMOTE_URL` finding. `unpkg.com`/`cdn.jsdelivr.net` remain denied, and the bundled NoClip JavaScript is still forbidden from referencing CDNs (`noclip-runtime.manifest.json`, `forbiddenRuntimeOriginMatches=0`). **NoClip stays.**
- **NuGet High fixed** — `Tmds.DBus.Protocol` `0.20.0` → `0.21.3` (GHSA-xrw6-gwf8-vvr9).
- 45 trailing-whitespace issues in `Strings.{ja,ko,zh}.resx` cleaned.

**Aurora Chamber EditViewer (2.244.2.0):**

- Map-only/stub scenes (e.g. `bsil03`) now render the **real battle stage** via the bundled noclip runtime with `?edit=1` — real underwater canyon + positioned monsters + drag gizmo — instead of the wrong field map or an empty grid. Scenes with exportable btlmap geometry still use MapViewer.
- **"Save positions" sidecar→bin merge** — gizmo deltas (`edits/<encId>.json`) convert to absolute coords over the `monster_live` anchor and merge into the DragBridge keyspace; consumed deltas only clear after a successful write.
- Phantom-Y gizmo fix; `DragSaveStatus` now bound in the UI.

**From 2.244.0.0/2.244.1.0:** self-sufficient NoClip (official-CDN data bootstrap + fetch-through — viewers work on a clean machine), 10-track music auto-import via bundled vgmstream, AI Assistant agent mode with executable `BytePatchAdapter` proposals (opt-in gate), separate game-folder picker, Aurora Chamber restored to the public catalog, Linux external-browser fallback.
