## Spira Reforge Studio v2.235.4.0

Primeira distribuição pública portátil do Editor para Windows x64.

### Instalação

1. Baixe `Spira-Reforge-Studio-v2.235.4.0-win-x64.zip`.
2. Extraia o ZIP inteiro para uma pasta gravável.
3. Execute `FFXProjectEditor.exe`.
4. Consulte `WINDOWS_FIRST_RUN.txt` dentro do pacote caso o Windows solicite algum pré-requisito.

O pacote é self-contained e inclui os runtimes e avisos de terceiros necessários. Ele não inclui arquivos do jogo.
