## What's in 2.245.1.0

**Linux lane merged into the release line:**

- `linux-x64` now resolves `Avalonia.X11` + `Tmds.DBus.Protocol`; `win-x64` resolves `Avalonia.Win32` + WebView2 — restore (`RuntimeIdentifiers`) and build (`RuntimeIdentifier`) select the same graph, and unsupported RIDs fail closed.
- Portable path resolution across extras/tools (no machine-bound `D:\`-style roots); viewer hosts fail closed when a policy or backend is unavailable, including pinned noclip origins.
- WebView2 navigation policy deduplicated into the shared `WebView2NavigationPolicy` (top-level/frame navigation, web-message and download gates).

**Fixes riding along:**

- ATEL emitter: less-than-or-equal emits `0x0A`, less-than emits `0x0B` (greater-than variants swap operands) — restores the documented opcode semantics.
- Treasure map scanner: event disassembly `PUSHI`/`PUSHII` immediates are now recognized, so `obtainTreasure`/`obtainTreasureSilently` calls recover treasure IDs — 124 confirmed chest candidates with recovered positions on the real corpus.
- Studio branding unified on `SpiraReforgeStudio.ico`; payload allowlist/tool contracts regenerated for this exact payload.
